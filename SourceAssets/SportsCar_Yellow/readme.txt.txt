This Low Poly Auto Racing Car contains one vehicle (with separate wheels) which has been textured, UV mapped, and unwrapped. The mesh and texture (after compression) is very small and can be used in a street racing game. The asset can be easily imported into Unity or an open-source game engine like Superpowers.
